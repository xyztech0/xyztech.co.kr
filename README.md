# XYZTECH Website — v23

GitHub Pages에서 별도 빌드 없이 실행되는 정적 홈페이지입니다.

## GitHub Pages 게시

1. ZIP 파일을 해제합니다.
2. 압축을 푼 폴더 안의 파일 전체를 GitHub 저장소 최상위에 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**, `main`, `/ (root)`를 선택하고 저장합니다.

`index.html`이 저장소의 최상위에 있어야 합니다.

## 수정할 위치

- 공통 디자인: `assets/styles.css`
- 공통 메뉴·하단 회사정보: `assets/main.js`
- 메인페이지: `index.html`
- 회사소개·조직도·확인서: `company.html`
- 사업분야: `services.html`
- 기술역량: `capabilities.html`
- 프로젝트: `projects.html`
- 문의: `contact.html`
- 공지사항: `notices.html`
- 디자인 검수 메모: `DESIGN_REVIEW.md`

문의 폼은 GitHub Pages에서도 작동하도록 `ceo@xyztech.co.kr` 메일 작성창을 여는 방식입니다. 서버 저장형 문의 접수는 추후 별도의 폼 서비스 또는 서버 연결이 필요합니다.

## v22 수정

설계·제작 수행 범위 반영, 회사소개/사업분야/문의 드롭다운 및 모바일 메뉴, 회사소개 고정 목차, 지그/자동화설비 중심 사업분야, 공지사항 빈 페이지를 적용했습니다.

프로젝트 이미지는 간략 형상 참고 자료이며 실물 촬영 사진이 아닙니다. 과거 프로젝트의 제작 여부는 단정하지 않습니다. 문의서는 기존 메일 작성 방식이며 공지사항은 notices.html에서 직접 편집합니다.

## v24 메뉴 변경

PC 상단 메뉴 하나를 열면 회사소개·사업분야·문의의 하위 항목이 세 열로 동시에 나타납니다. 흰색 86% 불투명도와 약한 배경 흐림을 적용했습니다. 마우스 이탈·외부 클릭·Escape로 닫고, 키보드 아래 방향키로 해당 열에 진입할 수 있습니다. 모바일 메뉴는 기존 터치 펼침 방식을 유지했습니다.

## v25 메뉴 이동
상단 회사소개·사업분야·문의 클릭 시 각각 인사말·지그·문의 항목으로 이동합니다. PC의 반투명 전체 메뉴는 마우스를 올려 펼치며, 모바일은 제목으로 이동하고 + 버튼으로 하위 메뉴를 펼칩니다.

## v26 인증서 전시
인증서 명칭과 설명을 먼저 배치하고 워터마크가 적용된 문서 전체를 본문에 표시합니다. 이미지와 원문 보기 링크를 제거하여 별도 클릭 없이 PC 3열·모바일 1열로 확인할 수 있습니다.

## v29 CATIA 사업분야
지그·자동화설비는 흰색 상단 제목과 이미지/설명 행으로 구성했습니다. 전달받은 PNG 5종을 수정 없이 assets/cad에 사용합니다. 로봇 핸드 및 스탠드의 이미지 영역은 의도적으로 비워 두었습니다. 기존 홈·프로젝트 이미지는 유지합니다.

## v30 포괄적 사업 소개
지그·자동화설비의 세부 종류별 소개를 포괄적 설계·제작 안내와 형상 예시 갤러리로 변경했습니다. 홈의 사업 요약과 문의 분야도 통일했으며, 소개되지 않은 제품·공정도 조건에 따라 상담할 수 있음을 명시했습니다.

## v31 메인 홈 간소화
홈을 핵심 메시지, 지그·자동화설비, 기업 인증, 문의의 네 영역으로 정리했습니다. 사업 이미지는 최신 CATIA PNG를 사용하고 세부 형식은 예시로 표시합니다. 기존 홈의 반복 소개, 프로젝트 나열 및 긴 업무 절차는 제거했으며 상세 페이지는 유지합니다.

## v32 메인 홈 전문성 보완
첫 화면에 실제 제공된 CATIA 형상 예시를 배치하고, 포괄적 사업영역·설계와 제작 과정·워터마크 인증서 3종·상담을 연결했습니다. 과장된 수치나 미확인 실적은 추가하지 않았습니다.

## v33 AI 산업 이미지
홈의 기계 이미지 3종을 내장 이미지 생성 도구로 제작한 사진풍 이미지로 교체했습니다. 인증서와 상세페이지의 CATIA 이미지는 유지합니다. 모든 홈 기계 이미지에 AI 연출 표시를 적용했습니다.
이미지 제작 방향: 메인 — 금속 가공면·정밀 고정구 클로즈업, 지그 — 로케이터와 클램핑 구조의 산업 사진, 자동화 — 안전 커버가 있는 조립 자동화설비. 공통 조건은 사진풍, 실버·그라파이트 톤, 로고·문자·과도한 SF 효과 제외입니다.
