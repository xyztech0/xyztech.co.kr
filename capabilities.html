CAPABILITIES

공정 목적과 제작조건을 설계 기준으로 전환하고, 검토 가능한 3D 데이터와 제작 가능한 2D 도면으로 완성합니다.

Engineering Workflow

설계 전 과정에서
확인해야 할 조건들

프로젝트마다 범위는 달라질 수 있지만, 요구조건·기구 구성·동작·제작성·데이터 정합성을 일관되게 검토합니다.

01 / REQUIREMENT

요구사항·공정 검토

고객이 제공한 자료와 협의 내용을 바탕으로 설계 목적과 적용조건을 정리합니다.

  • 워크 및 기준정보 확인
  • 자동화 대상과 작업 순서 검토
  • 설치조건과 연결부 확인
  • 납품 데이터와 일정 정의
02 / CONCEPT

구상설계·기구 구성

설비와 지그의 주요 구조, 유닛 구성과 작동 방향을 설계 초기 단계에서 구체화합니다.

  • 장비 및 Jig 구상설계
  • 구동방식과 구매품 검토
  • 작업·정비 조건 검토
  • 설계 방향 협의
03 / 3D DESIGN

3D 기계설계

형상, 조립관계와 작동조건을 반영하여 제작 검토가 가능한 3D 모델을 구성합니다.

  • Assembly·Part Modeling
  • 지그 및 자동화기구 설계
  • 표준품 배치와 사양 반영
  • 동작 위치별 구조 검토
04 / VERIFICATION

간섭·접근성 검토

설비 작동과 조립 과정에서 발생할 수 있는 간섭과 공간 문제를 사전에 점검합니다.

  • 부품 및 유닛 간섭 확인
  • 로봇·용접건 접근성 검토
  • 조립·분해 가능성 검토
  • 작업자와 유지보수 공간 고려
05 / 2D DRAWING

2D 제작도면

부품 제작과 조립에 필요한 치수, 공차와 가공 정보를 기준에 맞게 표현합니다.

  • 조립도 및 부품도 작성
  • 치수·공차·재질 정보
  • 구매품 및 부품표 정리
  • 도면 정합성 확인
06 / REVISION

설계변경·데이터 관리

검토와 협의 결과를 설계에 반영하고 변경 이력과 납품 데이터를 관리합니다.

  • Revision 반영
  • 3D·2D 데이터 정합성
  • 링크 및 파일구조 관리
  • 최종 납품자료 확인
